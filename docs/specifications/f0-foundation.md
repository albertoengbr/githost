# F0 specification — Foundation

Status: ACCEPTED (2026-10-17) · Evidence:
[testing/f0-evidence.md](../testing/f0-evidence.md)

## Objective

Establish the engineering foundation of GitHost so that every later phase
builds on verified ground: repository skeleton, configuration, logging,
SQLite with versioned migrations, minimal HTTP server, CLI, tests,
tooling and documentation.

## Deliverables and acceptance criteria

| 2 | Requirements specification | docs/requirements.md covers functional (FR-xxx), non-functional (NFR-xxx), security (SEC-xxx) requirements with stable IDs | PASS |

## Out of scope (explicit)

Anything requiring the Git engine (executor, transports, auth) — F1;
web UI/API — F2; backups — F3. No platform is declared officially
supported (native validation is still pending beyond the dev host).
